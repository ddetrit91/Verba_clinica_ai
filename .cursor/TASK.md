# Задачи

## Сделано

- Лендинг, запись, админка, общая база, бот, дубль заявок в группу
- Мокап: 6 медиков и около 20 заявок
- Светлая и тёмная темы
- Next.js 16.4.3 и TypeScript 7.0.2
- Редизайн в духе шаблона ITAgency: белая шапка, тёмный герой, синие кнопки. Контент клиники сохранён
- Фон героя: случайное видео YouTube о здоровье, без звука, по кругу, с затемнением и прелоадером
- Рефакторинг домена: booking разделён на medics, slots, appointments, report; сиды и HTTP-хелперы вынесены
- Бот: /start и кнопка «Записаться» снова работают при запущенном `npm run bot`; меню команд в Telegram; webhook снимается перед polling; сайт и бот пишут в Neon Postgres
- Напоминания в личку Telegram: за час и за 5 минут из процесса бота, плюс кнопка «Напомнить» в админке
- Mini App `/tg`: календарь записи, источник `telegram` при подписанном `initData`, кнопка бота по `WEBAPP_URL`

## Дальше

- Держать процесс `npm run bot` включённым, пока нужна запись из Telegram
- Для кнопки Mini App прописать `WEBAPP_URL` (HTTPS туннель на `/tg`) и перезапустить бота одним процессом
- `TELEGRAM_GROUP_CHAT_ID` уже используется как адрес дублей. Сейчас это личный чат, не группа. Менять значение только если появится отдельная группа
- Сменить `ADMIN_PASSWORD` и `ADMIN_SECRET`, если макет уедет с этого компьютера
