# Рефакторинг без смены поведения

Сайт, календарь, админка и Telegram-бот остаются как есть. Меняется только внутренняя раскладка кода.

## Что не трогать

- Внешний вид, темы, герой с видео, тексты и телефон.
- Адреса API (`/api/doctors`, `/api/calendar`, `/api/slots`, `/api/appointments`, `/api/admin/...`). Слово `doctors` в URL остаётся, в домене по-прежнему «медик».
- Правила слотов, телефон `+998`, уведомления в Telegram, сиды и пароль админки.
- [app/globals.css](app/globals.css): порядок правил уже влияет на меню и героя, файл не дробить.
- [app/page.tsx](app/page.tsx), [components/BookingDesk.tsx](components/BookingDesk.tsx) и [components/AdminDesk.tsx](components/AdminDesk.tsx): это цельные экраны, резать их на мелкие куски не нужно.

## Домен

Сейчас [lib/booking.ts](lib/booking.ts) сразу делает каталог медиков, слоты, заявки и отчёт админки. Разнести по файлам и обновить импорты у API, бота и страниц:

- `lib/rows.ts` — чтение строк SQLite и сборка `Medic` / `Appointment` (сейчас `mapMedic`, `mapAppointment`, `readSchedule`).
- `lib/medics.ts` — `listMedics`, `getMedic`, `parseMedicInput`, `createMedic`, `updateMedic`.
- `lib/slots.ts` — `daySlots`, `monthAvailability`, `upcomingOpenDays`.
- `lib/appointments.ts` — `createAppointment`, `cancelAppointment`, `listForTelegram`. Два почти одинаковых SQL в `appointmentsBetween` свести в один запрос.
- `lib/report.ts` — `loadReport`.
- [lib/booking.ts](lib/booking.ts) удалить, чтобы не остался пустой фасад.

## База

[lib/db.ts](lib/db.ts) оставить подключением, схемой и миграцией телефона `+7` → `+998`. Мокап-медиков и вставку заявок вынести в `lib/seed.ts`. `getDb()` по-прежнему сеет базу только если медиков ещё нет, и сиды по-прежнему не шлются в Telegram.

## API

В каждый route сейчас копируются `runtime`, `dynamic`, разбор JSON и проверка админа. Добавить `lib/http.ts` с `readJson` и `requireAdmin`. Сами `export const runtime` и `dynamic` оставить в файлах маршрутов: Next читает их только оттуда.

## Герой

[components/HeroParallax.tsx](components/HeroParallax.tsx) совмещает параллакс карточки и плеер YouTube. Плеер (список роликов, mute, цикл, прелоадер, скрытие кнопки запуска) перенести в `components/HeroVideo.tsx`. Параллакс и разметка секции остаются в `HeroParallax`.

## Проверка

- `npx tsc --noEmit`
- Главная, `/book` и `/admin` на текущем dev-сервере: запись, слоты и вход в админку ведут себя как раньше.
