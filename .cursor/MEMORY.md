# Память

- Продукт: клиника «Верба», Казань, ул. Садовая, 18, телефон +998 71 200-18-42. Валюта — сум (UZS). Учебный макет.
- Стек: Next.js 16.4.3, TypeScript 7.0.2, React 19, Tailwind 4, Neon Postgres через `pg` (node-postgres), grammY.
- Вид: тёмный шаблон как у демо ITAgency (белая шапка, синие кнопки #2563EB). Герой: случайное беззвучное зацикленное реалистичное видео YouTube (приём, забота о пациентах), затемнение, прелоадер. Светлая тема — класс `light`. Карточки медиков ведут на `/book?medic=`.
- Вид сайта: тёмная витрина в духе шаблона ITAgency, белая шапка, синий акцент. Светлая тема классом `light` на `html`.
- Домен: медики в `lib/medics.ts`, слоты в `lib/slots.ts`, заявки в `lib/appointments.ts`. Сиды — `lib/seed.ts`.
- База: Neon Postgres, проект связан через `.neon` (ветка `production`). Сайт, бот и Vercel ходят в одну базу. `DATABASE_URL` — pooled, обычные запросы. `DATABASE_URL_UNPOOLED` — прямое подключение, миграция схемы при старте. Файл `data/clinic.sqlite` больше не используется. Пустая база при старте получает сиды (6 медиков). У шести учебных медиков есть портреты в `public/medics`, колонка `medics.photo`.
- Запись: день, время и медик. Источник `site` или `telegram`.
- Дубль новой заявки и отмены: только `lib/notify.ts` в чат `TELEGRAM_GROUP_CHAT_ID`. Другого адреса нет. Сейчас это личный чат (положительный id, не id бота). Сиды в Telegram не уходят. Без переменной заявка всё равно сохраняется. Подтверждение клиенту в диалоге бота — отдельно, только у того, кто записался из Telegram.
- Время слотов считается по локальным часам машины.
- Демо-пароль админки: `verba-admin` (в `.env`, не секрет продакшена).
- Бот: сообщения принимает Vercel, адрес `/api/telegram` (webhook). Локальный `npm run bot` сам не слушает чат. `BOT_POLLING=1` снимает webhook и снова требует включённый компьютер. Шаги записи (имя, телефон) лежат в таблице `bot_sessions`. Напоминания: бесплатный Vercel не даёт cron каждую минуту, поэтому точные напоминания за 5 минут без отдельного планировщика не гарантированы. При входящем сообщении бот дополнительно проверяет просроченные напоминания.
- Mini App: страница `/tg`, тот же календарь, что `/book`. Скрипт `telegram-web-app.js`, `ready()` и `expand()`. Внутри Telegram заявка уходит с `source: telegram` и `telegramUserId` (подпись `initData`). Без пользователя Telegram заявка сохраняется как с сайта. Имя можно поправить, телефон +998 обязателен.
- Кнопка Mini App: `WEBAPP_URL=https://verba-clinica.vercel.app/tg`. Кнопка меню чата «Запись» открывает эту страницу. Без пользователя Telegram заявка сохраняется как с сайта.
- Напоминания: `lib/reminders.ts`, таймер в процессе бота раз в минуту. Час — один раз, когда до начала больше 5 и не больше 60 минут. Пять минут — один раз, когда до начала больше 0 и не больше 5 минут. После начала и для отменённых не шлём. Колонки `reminder_hour_sent` / `reminder_soon_sent`: 0 ждёт, 1 отправлено, 2 больше не пробуем (время прошло, учебный id, или ошибка). Сбой сети или 429 повторяем до 3 раз и не помечаем отправленным. 400/403 (бот заблокирован, чат не найден) сразу ставим 2. Сиды не пишут в Telegram: id вида `5000 + номер` меньше 100000, такие строки помечаются 2 без сообщения. Кнопка «Напомнить» в админке шлёт сразу и флаги автонапоминаний не меняет. Без настоящего `telegram_user_id` ответ: «У клиента нет Telegram, напомнить нельзя.»

## Команды

- `npm run dev` — сайт
- `npm run bot` — один процесс long polling. Второй `getUpdates` даёт 409
- Сиды появляются сами, если в Neon ещё нет медиков. Файл sqlite для этого не нужен

## Neon

- CLI 8.18.0. Проект связан: `neon.ts`, `.neon`. `neon deploy` на Free-плане не проходит: в `neon.ts` включён AI Gateway, его не меняли. Auth, Functions, Object Storage, Realtime и AI Gateway этим деплоем не поднимались. Postgres взят командой `neon connection-string` (pooled и прямая строка) и прописан в `.env` и в production Vercel (`ddetrit/verba-clinica`). Прод: https://verba-clinica.vercel.app — `GET /api/doctors` отдаёт 6 медиков из Neon.
- Навыки пользователя (`neon`, `neon-postgres`, `neon-auth`, `neon-functions`, `neon-object-storage`, `neon-ai-gateway`, `neon-realtime`) стоят в `~/.agents/skills` и были актуальны.
- MCP для Cursor: `.cursor/mcp.json`, только URL `https://mcp.neon.tech/mcp` (OAuth, без ключа). При первом вызове Cursor попросит вход в Neon.
