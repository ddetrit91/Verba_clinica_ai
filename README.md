# Клиника «Верба»

Локальная запись на приём: лендинг, календарь (день, время и медик), админка и Telegram-бот. Сайт и бот пишут в одну базу Neon Postgres. Новая заявка и отмена дублируются в чат из `TELEGRAM_GROUP_CHAT_ID`.

Учебный макет. Это не медицинская организация.

## Запуск

```bash
npm install
npm run dev
```

Сайт: http://localhost:3000

Админка: http://localhost:3000/admin  
Локальный пароль: `verba-admin`

Бот, когда в `.env` указан токен:

```bash
npm run bot
```

Переменные описаны в `.env.example`. Без токена сайт работает, бот завершается с просьбой добавить `TELEGRAM_BOT_TOKEN`.

Мокап (6 медиков) появляется сам, если в Neon ещё нет медиков. Файл `data/clinic.sqlite` больше не используется.
