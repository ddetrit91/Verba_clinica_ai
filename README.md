# Клиника «Верба»

Локальная запись на приём: лендинг, календарь (день, время и медик), админка и Telegram-бот. Сайт и бот пишут в одну базу `data/clinic.sqlite`. Новая заявка и отмена дублируются в группу клиники.

Учебный макет. Это не медицинская организация.

## Запуск

```bash
npm install
npm run dev
```

Сайт: http://localhost:3000

Админка: http://localhost:3000/admin  
Локальный пароль: `verba-admin`

Бот, когда в `.env` указан токен:

```bash
npm run bot
```

Переменные описаны в `.env.example`. Без токена сайт работает, бот завершается с просьбой добавить `TELEGRAM_BOT_TOKEN`.

Чтобы заново загрузить мокап, остановите сайт и бота и удалите `data/clinic.sqlite`.
