# Контекст

Клиника «Верба». Запись только к медикам: день, время, специалист. Барбера в продукте нет.

Шесть мокап-медиков: Соколова (терапевт), Морозов (кардиолог, плотнее в записях), Лебедева (невролог), Орлов (ЛОР), Крылова (дерматолог), Волков (педиатр, свободнее).

Один интервал на день недели. Слот по умолчанию 30 минут. Повторная запись на тот же слот отклоняется, отмена слот освобождает.

База — Neon Postgres (`pg`): сайт, бот и Vercel. Новая заявка и отмена уходят в чат из `TELEGRAM_GROUP_CHAT_ID` (сейчас личный чат, не id бота): номер, источник, медик, дата и время, пациент, телефон. Пациенту про этот чат не сообщаем.
